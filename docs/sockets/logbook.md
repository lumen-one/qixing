# 记录插座

记录册（日历上圈出来的段 + 一个月一句的月记）住在独立的 `记录.md` 里，一个文件装全部记录。
**与主线不相交**：没有主线照样加段，主线归档也不改这里的任何状态——记录册没有"只读"这一说。

**LogBookRepository / LogBookCodec**：`domain/logbook.dart` 的 `LogBook` 是一份不可变快照
（`LogSegment` 列表 + `MonthNote` 列表）；编解码在 `repository/{logbook_codec,
logbook_repository,markdown_logbook_codec}.dart`，服务在 `application/logbook_service.dart`。
每条命令都是"读整份 → 改一处 → 整份写回"，两个引擎同时改按后写者胜（与 `主线.md` 同档）。

**增删改按内容定位，不传下标**：身份是 `LogSegmentRef`（起止日 + 当时的原文）。服务每条
命令都先重新读盘、再按起始日排序，界面算出的下标只对"读盘前那一刻"成立——中间另一份引擎
（悬浮面板）或人改了 `记录.md`，同一个下标就落到别人那条圈上，改错和删错都不报错。按内容
找回原条目之后：改找不到就报错（不猜），删找不到就当已经删掉（幂等）。同起止、同文字的两
条取第一条，代价登记在 [架构文档](../architecture.md) §11。

**加段 / 改起止日期要验区间**：新段与已有段只要共用一天就拒绝，报出撞到的那一段的起止与
文字，不自动裁剪——裁剪会悄悄改掉用户亲手拖出的范围。`add` 与 `update` 都验，`update` 验的
时候排除它自己；只改文字不走这条。读盘不校验也不迁移。

**月记单独一条命令**：一个月只留一条，再写就是改，空文本 = 删掉这个月那条；它不覆盖任何
一天，所以不参与区间校验。
