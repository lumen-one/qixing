# B.10 `记录.md`（日历上的记录段与月记）

**一个文件装全部记录**，是记录页唯一的数据源。它与 `主线.md` 没有任何关系——主线归档、
勾完步骤都不改这里一行，没有主线的时候它照样在写。应用维护整份文件，Obsidian 里可读可
改，读进来的改动生效，保存时正文按模型重写（局限见本节末）。

```markdown
### 记录

- 2026-10-19 ~ 2026-10-21 连续三天都在写第三章，比预期快
- 2026-10-20 单天一条就只写一个日期

### 月记

- 2026-10 这个月把第三章写完，图的配色也重画了一遍
```

- 两段：`### 记录`、`### 月记`（写成 `##` 也认）。`### 记录` 恒在，`### 月记` 一个月
  都没写时不落这一段；
- **记录**一条一行：`- <起始日> ~ <结束日> 文字`，单日只写一个日期（`~` 两侧有空格）。
  起止写反了对调；文字可含除换行外的任意字符（写回时压成一行）；
- **月记**一条一行：`- <年>-<月> 文字`（月份补两位，如 `- 2026-10 …`）。一个月只留一条，
  文件里写了重复行以**后出现的那条**为准；月记不覆盖任何一天，所以它不进日历、也不进
  记录列表（与记录段的分工见 [记录页](../panels/record.md)）；
- **记录段互不重叠**：写入撞上已有段就拒绝，报出撞到那一段（[记录插座](../sockets/logbook.md)）。
  读盘不校验也不迁移——手写的相交段归 [架构文档](../architecture.md) §11；
- 排序：记录按起始日升序、月记按年月升序，保存时自己维持；
- 文件不存在 = 一条记录都没有；第一次写入才创建它；
- **已知局限**（登记在此，不另做）：正文由应用重写，不属于这两段的自由文字下次保存会
  消失（与 `主线.md` 同档）；两个引擎同时改同一份文件按后写者胜（与 `routines.md` 一致）。
