# B.6 `主线.md`（主线 / 行为链）

**一个文件装全部主线**（在跑的 + 已归档的）。与双文档那一套不同：**应用维护整份文件**，
Obsidian 里可读可改，读进来的改动生效，但下一次保存会按模型重写正文（局限见本节末）。
**主线只有行为链**：日历上的记录与月记住在另一份文件（[记录文件](logbook.md)）。

```markdown
---
id: ml-20261021-4f2a
title: 论文冲刺
created: 2026-10-18T09:00
---

### 行为链

- [ ] 列提纲
- [x] 写第三章 完成 2026-10-19,21:30 备注：卡了两小时，后来用番茄钟推过去
- [ ] 通读一遍
```

- 一条主线 = 一个 frontmatter 块：`id`（时间戳 + 随机尾巴）/ `title` / `created` /
  `completed`（有值 = 已完成归档，值为完成时刻）/ `abandoned`（有值 = 已废弃归档，值为废弃
  时刻）。两个都空 = 在跑；两个都有值（手改出来的边角）按完成算。未知字段行**原样保留**
  （与 B.5 同档）；
- 正文一段：`### 行为链`（写成 `##` 也认）。一条一行复选框，与 `tasks.md` 同族：
  `- [ ] 标题` / `- [x] 标题 完成 <日期,时间> 备注：文字`；字段从右往左剥——先 `备注：`，
  再 `完成 <时刻>`，剩下的全是标题（标题里带空格、带"完成"字样都不影响）；
- **复选标记才是完成判据**，`完成` 是可选时刻（缺 = 勾了但没时刻）。步骤行上显示的
  "完成 10 月 19 日 21:30"就是从这一列读的，不另存一份；
- 排序：在跑的在前，已归档的按归档时刻（`completed` 或 `abandoned`）从新到旧；归档只改
  状态，不删任何数据；
- 旧版文件里的 `### 记录` / `### 月记` 两段**不再读**：要留的内容自己搬进 `记录.md`
  （[记录文件](logbook.md)），下一次保存重写正文时这两段会一起消失，读盘会给一条告警；
- **已知局限**（登记在此，不另做）：正文由应用重写，人在正文里加的自由文字（不属于
  步骤行的行）下次保存会消失；标题里出现 ` 完成 ` 或 ` 备注：` 会被当成字段锚点
  （与 `tasks.md` 同一类边界）；两个引擎同时改同一份文件按后写者胜（与 `routines.md` 一致）。
