# B.9 `速记.md`（标签页便签）

**一个文件装全部速记**，与 `主线.md` 同族：应用维护整份，Obsidian 里可读可改，读进来
的改动生效，保存时正文按模型重写。

```markdown
---
id: sn-20261104-3f9c
title: 十一月
created: 2026-11-04T16:20
---

## 本周

- 侧边栏把手
- 速记的折叠

---
id: sn-20261105-7a01
title:
created: 2026-11-05T09:02
---

还没想好写什么。
```

- **一条速记 = 一个 frontmatter 块**：`id`（`sn-` + 日期 + 随机尾巴）/ `title` /
  `created`。块从一行 `---` 开头，正文从闭合的 `---` 之后开始；
- **块的边界靠下一段的 `id:` 认**：正文里单独一行 `---` 照旧是水平分割线，只有
  "`---` 之后紧跟着一行 `id:`"才算下一条速记开始（与 `主线.md` 同一套判据）；
- `title` 可以为空（标签显示『未命名』）。**文件里不存折叠状态、不存当前选中哪个标签**
  ——两者都是内存态；
- 正文是这条速记的 markdown 原文，原样保留：`#` 标题、列表、引用、代码块都不做规范化；
- 顺序 = 文件顺序 = 标签栏顺序；应用不改排序，新增追加到末尾；
- 缺 `id` 的块跳过（记 warning）；缺 `title` 的块照收；
- **已知局限**（登记在此，不另做）：
  - 正文由应用重写：块外的自由文字（不属于任何一条速记的行）下次保存会消失；
  - 正文里先写一行 `id:`、再写一行 `---`，会被当成下一条速记的开头；
  - 两个引擎同时改同一份文件按后写者胜（与 `routines.md`、`主线.md` 一致）。
