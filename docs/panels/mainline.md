# 6.9 主线（顶栏名字 → 覆盖页）

**一句话**：顶栏第二行永远显示"现在在推的那一件大事"；点开是一块盖住整块面板的页面——
第一页是行为链，向左横滑是记录（日历），顶栏那个名字是唯一入口。

- **同时只有一条主线**在跑。完成后归档（`tasks/主线.md` 里状态改"已完成"），顶栏第二行
  回到『＋ 新建主线』——不存在"切到另一条在跑的"这种操作，也没有并行几条的列表；
- **覆盖页盖住整块面板**（含面板头与页序圆点），自带标题行：
  `[返回] 主线名 … [1/2] [✎] [完成主线]`。退出三条路：左上『返回』、系统返回键
  （先收编辑态，再退覆盖页）、**内容滚到最底再继续上滑**（跟手推回，上推过 72dp
  或向上快甩才关）。两页各有一条纵向列表：行为链整条滚到底、记录页的下半区
  （本月记录列表）滚到底——日历格子那一块没有纵向滚动，那里不接这条手势。
  退出即回原来那四页，**原来的页位置不变**；
  - **进出是滑动**：点开时整块从面板顶边上方滑下来（260ms、缓出），退场原路滑回
    （200ms，比进场快——收回去要利落）；上滑退出的那一段是跟手（推多少走多少），
    松手才补满或弹回；滑动中露出的部分裁在面板圆角内，退场途中覆盖页不再接手势。
    桌面左栏共用同一个面板，两边一致；桌面上这两页不放鼠标拖拽，没有触屏
    overscroll，退出走『返回』；
- **两页**：第 1 页**行为链**、第 2 页**记录**（日历）。翻页有两条路：
  1. **点页头那颗 `1/2`**（点一下切到另一页）；
  2. **记录页的下半区向右滑**（记录列表 / 空提示那半边）就回行为链——**横滑按区域
     分工**：日历格子里是"按住拖选日期圈一段"，下面那半边没有日历可圈，就让给翻页。
     第 1 页仍可向左横滑去记录页。
  横滑/翻页只发生在覆盖页内部，不动面板本身的页序；
- **行为链的画法**：纵向一条链——节点 + 连线，从上往下读：
  - 完成的步骤：节点**实心**、文字加**横线**（删除线）、连线转实色；
  - 未完成的步骤：节点空心、连线虚线；
  - **第一个没勾的**是"下一步"：节点加一圈强调色描边；
  - 点**节点** = 勾选 / 取消勾选（记/清完成时刻）；点**文字** = 打开这一步的编辑（改名 /
    写备注 / 看完成时刻）——勾选是高频动作，所以给它最小的靶；改名是低频，放在文字上；
  - 全部勾完 → 标题行出现『完成主线』。**不自动归档**：勾完只是"可归档"，要显式点一下；
- **记录 = 日历上手动圈出来的段**（下称记录段，不是按天写流水）：
  - 上半区是**不滚动的月历一屏**（周一开头，今天淡圈），每天格子里只放日期数字；
    **有内容的日子**（勾过步骤或记录段覆盖）在数字下留一个小点；每段记录在覆盖的周里
    画一根细条，跨周按周分段，**细条上不写字**；
  - **记录段互不重叠**：一段占住的日子不许再落第二段，写入时撞上已有段就拒绝并报出撞到
    哪一段（不自动裁剪）。因此同一周里的细条横向不相交，不必叠放；手工编辑 `主线.md`
    写出的重叠段不归应用管（[架构文档](../architecture.md) §11）；
  - **按住某天拖到另一天** → 拖过的连续日期高亮成一条 → 松手弹输入框写文字 → 落成一段
    记录。一次只圈**连续**日期；同一段里不必每天都有内容；
  - 下半区**不依赖选中日**，进来就常驻列出与本月相交的全部记录段：每段一张卡，左侧一条
    强调色竖线、卡片里是完整正文（不截断），下面一行小字写起止日期与天数。文字不用点开
    才看得见；点卡片 = 改文字 / 删这一段；
  - **点某一天**只做两件事：把覆盖这一天的那张卡滚动到可见并高亮、日历上对应细条一起
    加深；选中日若勾过步骤，卡列表顶部补一小块当天的自动流水（时刻 + 步骤名 + 写在步骤
    上的备注）。**记录是人写的那一半，流水是勾选自动记的那一半，互不替代**；
  - 上下比例：月历在上半区，下半区记录列表拿更多高度；列表不满一屏也能滚到底，
    接得住上滑退出；
- **月记（按月一行）**：月头中间那行年月是**视图开关**——点它，上半区从月历换成这一年的
  十二行：
  - 每行左边是月份（`1 月`…`12 月`），右边一行文字；没写的是灰字『记一句』，写过的那行
    左侧带一个小圆点；
  - 点某一行 = 写 / 改这个月的一句话。**一个月只留一条**，再写就是改；有字的才能删；
    输入框里不写例句——上面那行标题已经说了写什么；
  - 月记模式下左右箭头翻**年**，再点月头（此时只显示年份）切回月历；
  - **月记不进日历**：它不覆盖任何一天，日历格子上的小点仍然只看勾过的步骤与记录段——
    按月记点亮整月的小点等于什么都标不出来；
  - 归档后月记同样只读；
- **编辑**（标题行 ✎）：同一页切成编辑态——主线名变输入框；每个步骤一行输入框，右侧
  删除按钮、长按拖动把手（组内可拖，改的是行为链顺序）；末尾『＋ 添加一步』；底部
  『保存』『取消』。保存一次落盘（改名 + 整条链一次写），取消原样退回。**记录段不进编辑态**：
  文字在"点记录卡"的对话框里改，删除也在那里；
- **归档与查看**：归档只改状态与归档时刻，不删任何数据。归档后主线只读——第 1 页底部
  永远有一行『已完成的主线 · N 条』，点开是归档列表（标题 + 完成日期 + 完成时几件/共几件），
  选一条进入**只读**查看（标题行换成『已归档』徽标 + 『返回当前』），行为链、记录段、完成时刻
  都还在；
- **存储**：`tasks/主线.md`，一个文件装全部主线（[主线文件格式](../formats/mainline.md)）。应用维护整份文件；Obsidian
  可读可改，读进来的改动生效，保存时正文按模型重写（局限登记在那份文件的『已知局限』）；
- **与任务的关系**：行为链步骤是主线自己的条目，**不绑任务、不进任务池与今日清单、不占
  工时、不参与调度、不响提醒**。想让某一步也进调度，就另建一条任务——这是有意的边界，
  不另做双向同步（写在 [UI 文档](../ui-interaction.md) §11）。
