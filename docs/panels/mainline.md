# 6.9 主线（顶栏名字 → 覆盖页）

**一句话**：顶栏第二行永远显示"现在在推的那一件大事"；点开是一块盖住整块面板的页面——
第一页是行为链，第二页是记录（[记录页](record.md)，另一次元的东西，与这条主线无关），
顶栏那个名字是唯一入口。

- **同时只有一条主线**在跑。结束它只有两条路：勾完全部步骤后**完成归档**，或者做不下去时
  **废弃归档**（都只改状态，`tasks/主线.md` 里分别记 `completed` / `abandoned` 时刻）；归档
  后顶栏第二行回到『＋ 新建主线』——不存在"切到另一条在跑的"这种操作，也没有并行几条的列表；
- **覆盖页盖住整块面板**（含面板头与页序圆点），自带标题行：
  `[返回] 主线名 … [1/2] [✎]`。退出三条路：左上『返回』、系统返回键
  （先收编辑态，再退覆盖页）、**内容滚到最底再继续上滑**（跟手推回，上推过 72dp
  或向上快甩才关）。第 1 页的纵向列表整条滚到底才接这条手势。退出即回原来那四页，
  **原来的页位置不变**；
  - **进出是滑动**：点开时整块从面板顶边上方滑下来（260ms、缓出），退场原路滑回
    （200ms，比进场快——收回去要利落）；上滑退出的那一段是跟手（推多少走多少），
    松手才补满或弹回；滑动中露出的部分裁在面板圆角内，退场途中覆盖页不再接手势。
    桌面左栏共用同一个面板，两边一致；桌面上这两页不放鼠标拖拽，没有触屏
    overscroll，退出走『返回』；
- **两页**：第 1 页**行为链**、第 2 页**记录**（[记录页](record.md)）。页头那颗 `1/2`
  **常驻**——没有主线时第 1 页是空态（新建入口），那颗 `1/2` 照样在，点得动、也照样能
  左滑过去。翻页有两条路：
  1. **点页头那颗 `1/2`**（点一下切到另一页）；
  2. **记录页的下半区向右滑**（记录列表 / 空提示那半边）就回行为链——**横滑按区域
     分工**：日历格子里是"按住拖选日期圈一段"，下面那半边没有日历可圈，就让给翻页。
     第 1 页仍可向左横滑去记录页。
  横滑/翻页只发生在覆盖页内部，不动面板本身的页序。**页头标题两页都是这条主线的名字**——
  页头属于整块覆盖页，记录页只是借它的头；
- **行为链的画法**：纵向一条链——节点 + 连线，从上往下读：
  - 完成的步骤：节点**实心**、文字加**横线**（删除线）、连线转实色；
  - 未完成的步骤：节点空心、连线虚线；
  - **第一个没勾的**是"下一步"：节点加一圈强调色描边；
  - 点**节点** = 勾选 / 取消勾选（记/清完成时刻）；点**文字** = 打开这一步的编辑（改名 /
    写备注 / 看完成时刻）——勾选是高频动作，所以给它最小的靶；改名是低频，放在文字上；
  - **标题过长就换行**，最多 4 行后省略；行高随内容长（最短 56dp），节点始终贴着第一行；
    备注那一行仍是单行省略，全文在编辑对话框里看；
- **结束这条主线的入口在进度行右端**（`0/1 已完成` 那一行的右边）：
  - 没勾完时是淡色**『废弃』**——不要求勾完，点一下确认后整条归档、不标记完成；
  - 勾完后那一位换成**『可归档』**提示，页底同时出现『完成主线并归档』一大颗（标题行最右
    也有一颗勾图标）。**不自动归档**：勾完只是"可归档"，要显式点一下。
  废弃不放在标题行：240dp 上那一行已经挤了返回 / 名字 / `1/2` / 铅笔，一颗"废弃"贴在最右端
  离返回只隔几个像素，误触代价太大；
- **编辑**（标题行 ✎）：同一页切成编辑态——主线名变输入框；每个步骤一行输入框，右侧
  删除按钮、长按拖动把手（组内可拖，改的是行为链顺序）；末尾『＋ 添加一步』；底部
  『保存』『取消』。保存一次落盘（改名 + 整条链一次写），取消原样退回；
- **归档与查看**：完成和废弃都只改状态与归档时刻，不删任何数据；归档后只读——第 1 页底部
  永远有一行『归档 · N 条』，点开是从新到旧的归档列表：一行一条，左边主线名，右边是
  『已完成』或『已废弃』徽标与归档日期。选一条进入**只读**查看：标题行只剩『返回当前』，
  第 1 页顶部一条横幅写『已归档 · 日期 完成/废弃 · 只读』，行为链与完成时刻都还在。
  归档查看是**单页**——页头不摆 `1/2`、也不接横滑，那是一次"回看"，不是继续写的地方。
  **归档不给恢复**：要重做就新建一条；
- **存储**：`tasks/主线.md`，一个文件装全部主线（[主线文件格式](../formats/mainline.md)）。
  应用维护整份文件；Obsidian 可读可改，读进来的改动生效，保存时正文按模型重写；
- **与任务的关系**：行为链步骤是主线自己的条目，**不绑任务、不进任务池与今日清单、不占
  工时、不参与调度、不响提醒**。想让某一步也进调度，就另建一条任务——这是有意的边界，
  不另做双向同步（写在 [UI 文档](../ui-interaction.md) §11）。
