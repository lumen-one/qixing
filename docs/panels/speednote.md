# 6.13 速记（灵感页下拉 → 标签页便签）

**一句话**：起一个标签页随手写字。不排期、不进清单、不响提醒。`#` 开头的行就是标题，
点标题收起这一节，长按改它。

## 入口：灵感页到顶之后再下拉

- 灵感页**已经滚到顶**，继续往下拉 → 覆盖页从面板顶边滑下来。跟手 1:1，松手时拉过
  72dp 或快甩（≥500 px/s）补满，没够弹回（与今日页进编排同一套，见
  [把手与面板](handle.md)）。
- 灵感页功能栏右端另有一颗图标，点它直接进。**编排那边只有手势**，第一次怎么进去
  没有视觉线索，代价登记在 [侧边栏](README.md) 的首次引导里；这一页的功能栏有位置，
  不再付一次。
- **编辑态不接下拉**：灵感页进编辑态时整页是一个输入框，往下拉是移光标，不抢。
- 灵感文件未配置或空态时一样能进：空态本身是可滚的容器，不是居中的一块。
- 退出三条路：左上『返回』、系统返回键、**正文滚到最底再继续上滑**。上滑只在"末尾
  之后"算退出，判据是位置不是手速（与编排同一个判据）。
- 桌面左栏共用同一份面板：下拉靠按住鼠标拖到顶再往下拖，退出走『返回』
  （[桌面布局](desktop.md)）。

## 页头三行

- 第一行：『返回』+ 当前视图名 + 右端『编辑』与「N 条」。视图名只有「速记」一段时
  不可点；将来加新的页面，就在这一行变成切换（与编排、支线共用一块壳是同一条路）。
  N 是速记总条数，不是当前这一条的标题数。
- 第二行：**标签栏**，浏览器式——一条速记一个标签，横向滚动，末尾一颗 `+`。
  - 点标签切换；长按标签改名，回车提交，清空回到『未命名』；
  - `✕` 只在当前那个标签上出现（每个标签都挂一颗的话，窄面板上标签名只剩两个字），
    删这条速记**不弹确认**，给撤销 toast：一次删一条，撤销恢复那一条原文；
  - **没有"打开 / 关闭"两态**：标签栏就是全部速记，删了才是没了。多一层"关掉但还在"
    的列表，找回来要多一次点击，不值。
- 第三行：**目录条**，正文里有 2 个及以上标题时才出现，横向滚动，点一项滚到该节并
  高亮一下。只有一个标题时它只是重复正文第一行，不摆。
- 覆盖页盖住整块面板（含面板头与页序圆点），与编排、主线同一套呈现；**页序仍是四页**，
  速记不是第五页。

## 展示态

- 正文按 `parseNotesMarkdown` 渲染——`#` 到 `######`、列表、引用、围栏代码块、行内强调，
  与灵感页同一套解析、同一套样式。不认表格、脚注、HTML、`==高亮==`。
- **标题就是折叠头**：标题行左侧一枚小三角，点标题收起这一节（收到下一个同级或更高级
  标题之前），再点展开。没有下级内容的标题不画三角。
- 折叠状态不落盘，也不跨次打开保留：退出覆盖页即全展开。
- **左右横滑切标签**：正文区向左滑到下一条、向右滑到上一条，切过去正文回到顶部。
  到头就停住，底部说一句『已经是第一条 / 最后一条』。**编辑态不接**——输入框里横向
  拖动是移光标、选字；标签栏与目录条是两条自己会滚的横向列表，也不接。
- **长按标题**弹一行菜单：
  - 『改名』一个输入框，只换 `#` 后面那段文字，`#` 的个数不动；
  - 『升一级』『降一级』只在 `#` 与 `##` 之间切——这两级是这一页的心智模型。手打的
    `###` 及更深照常渲染，只是菜单到不了那一档；
  - 『删除这一节』删的是"这个标题 + 它下面到下一个同级或更高级标题之前的全部内容"，
    给撤销 toast。

## 编辑态

- 页头『编辑』→ 正文换成占满页面的多行输入框，那颗按钮换成『完成』。
- `#` 开头的行**边打边放大加粗**，层级按 `#` 的个数。这只是显示，文件里仍是原文。
- 不做块编辑：单个输入框里能改字号，但"收起"要藏字，光标位置立刻乱，所以折叠只在
  展示态。
- **自动保存**：切标签、退出覆盖页、点『完成』、面板收起时落盘，没有『保存』『取消』。
  便签的心智是随手写，切走不该丢；代价是这一轮改动没法整段丢弃，要退靠自己撤销。
- **退出时顺手放焦点**：键盘跟着输入法连接走，而那连接只在输入框装卸时才关。退场
  动画要 200ms，悬浮面板收起来更是先摘窗口、后跑动画，等"页面被卸载"来收键盘就等
  不到——所以『完成』、退出覆盖页、面板收起这三条路都主动放焦点，不靠卸载兜底。
  关页只放焦点、不退编辑态：页面紧接着滑走，这时把正文换成展示态会看见字重排一下。
- `+` 新建落在末尾并切过去，直接进编辑态，光标在正文开头。
- 一条都没有时是空态：一句话 + 『新建一条』按钮（那一块也是可滚的，退出靠返回键）。

## 数据与同步

- `tasks/速记.md`：一个文件装全部速记，一条速记一个 frontmatter 块（`id` / `title` /
  `created`）+ 正文（[速记文件格式](../formats/speednote.md)）。文件里的顺序就是
  标签栏顺序，新建追加到末尾。
- 应用维护整份文件，Obsidian 里可读可改，读进来的改动生效；保存时按模型重写正文。
- 进局域网同步（[局域网同步](../sockets/sync.md)）：速记是用户自己写的正文，与任务、
  主线同权重；冲突仍由主机裁决。

## 不做的

- 不产生任务、不进今日清单与任务池、不参与调度、不响提醒、不占工时、不写 `.gtd/`。
  想把一句话变成待办，去别的页新建——这一页只管写。
- 不做富文本按钮、图片、内链、表格；markdown 怎么写就怎么显示。
- 标签栏不拖拽重排：顺序 = 文件顺序 = 新建顺序。
