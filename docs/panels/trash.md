# 6.14 回收站（已完成页下拉 → 回收站覆盖页）

- **入口**：已完成页**滚到顶之后继续往下拉**翻出来——与今日页翻编排（[今日编排](plan.md)）、
  灵感页翻速记（[速记](speednote.md)）同一条判据：只认手指拖（`dragDetails` 非空），
  鼠标滚轮"滚到头继续滚"不算；松手过 72dp 或向下快甩 500 px/s 才开。
  **空态也能拉**：已完成页空着、回收站里有东西，正是要找它的场景，所以那一页的空态
  与不满一屏的清单都带 `AlwaysScrollableScrollPhysics`。
- **出口**：页头『返回』、清单滚到底再上滑（跟手，行程与编排同一套）、系统返回键。
- **不换页序**：与其余覆盖页一样整块盖住面板（含面板头与页圆点），四页横滑里没有它。
- **设置页不再有这一项**：原来的『清空回收』那一行撤掉了，清空在页头
  （[UI 文档](../ui-interaction.md) §9 第 8 条）。

## 清单

- 一条 = 与已完成页同款的任务行（弱化呈现、无编号、不可拖），**行尾一颗『恢复』**，
  它左边是删除日期（同一年只写 `10-30`）。
- **按删除时刻倒序**：最近删的在最上面。删除时刻落在回收站文件的 `deleted_at` 键
  （[formats/sidecar.md](../formats/sidecar.md)『回收站专用键』）；老文件没有这个键时
  按文件修改时间兜底——写这个文件的那一刻就是删除时刻。
- 点条目 = 同一张只读详情卡（[今日清单页](today.md)），动作在长按菜单。
- **『恢复』**（行尾那颗与长按菜单里的是同一条命令）：按删除时记下的原行与原行号写回
  人类文档，任务回到删除前的状态——有截止的回今日清单 / 任务池，三无的回散件段，
  已完成过的回已完成页。恢复后行即从清单消失，并弹一条『已恢复「标题」』。
- **长按菜单两条**：恢复 / **彻底删除**（真删一条，二次确认，不可恢复）。
  这里没有『删除』——它已经在回收站里了，"再软删一次"没有意义。
- **空态**："回收站是空的"，加一句"删掉的任务会先落到这里"。

## 清空

页头右上角一颗图标钮（清单空时不可点），二次确认后删掉 `.gtd/.trash/` 里的全部文件
与老版本留在人类文档里的注释行（[formats/matching.md](../formats/matching.md) §B.4）。
清空后停在本页空态，不自动退回已完成页——『返回』一直在。

## 与已完成页的分工

已完成页的条目删掉之后落在这里（软删除，[formats/matching.md](../formats/matching.md) §B.4），
两页的条目形状一样，动作不同：已完成页给『恢复未完成』与『删除』，这一页给『恢复』
与『彻底删除』。
