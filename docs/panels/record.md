# 6.15 记录页（主线覆盖页的第 2 页）

**一句话**：日历上自己圈出来的那些段，加上一个月一句的月记。它**独立于主线**——没有
主线也能进，主线归档、勾完步骤都不改它一行；它只记人写下的东西。

- **入口**：主线覆盖页的第 2 页（[主线覆盖页](mainline.md)）。页头那颗 `1/2` 常驻，
  没有主线时也在；第 1 页向左横滑也过得来；
- **永远可写，没有只读态**：归档一条主线跟这一页没关系，翻开归档主线看的也是这同一本
  记录。数据全在 `tasks/记录.md` 一个文件里（[记录文件格式](../formats/logbook.md)），
  与 `主线.md` 不相交；
- **上半区是日历**（不滚动的月历一屏，周一开头，今天淡圈），每天格子里只放日期数字：
  - 每段记录在覆盖的日子上画一条**色带**：压在数字后面、约半行高、两端圆角，**色带上
    不写字**。跨周按周分段，继续到下一周的那一侧不留圆角、贴到格子边，读起来仍是连过去
    的一条；
  - **相邻的段不同色**：颜色按起始日顺序从主题那四色里取，换主题整套跟着换；下半区记录卡
    左侧那条竖线与它同色，一眼对得上；
  - **记录段互不重叠**：一段占住的日子不许再落第二段，写入时撞上已有段就拒绝并报出撞到
    哪一段（不自动裁剪）。因此同一周里的色带横向不相交，不必叠放；手工编辑 `记录.md`
    写出的重叠段不归应用管（[架构文档](../architecture.md) §11）；
  - **按住某天拖到另一天** → 拖过的连续日期高亮成一条 → 松手弹输入框写文字 → 落成一段
    记录。一次只圈**连续**日期；同一段里不必每天都有内容；
  - **点某一天**只做两件事：把覆盖这一天的那张卡滚动到可见并高亮、日历上覆盖它的色带
    一起加深。勾选步骤不在这一页留任何痕迹——没有小点、没有当天流水；
- **下半区常驻，不依赖选中日**：进来就列出与本月相交的全部记录段，每段一张卡，左侧一条
  与它同色的竖线、卡片里是完整正文（不截断），下面一行小字写起止日期与天数。文字不用
  点开才看得见；点卡片 = 改文字 / 改日期 / 删这一段；
- 上下比例：月历在上半区、记录列表拿更多高度（2:3）；列表不满一屏也能滚到底，接得住
  覆盖页的上滑退出：**滚到最底再继续上滑**就推回第 1 页（[主线覆盖页](mainline.md)）。
  日历格子那一块没有纵向滚动，那里不接这条手势；横滑按区域分工——日历里归拖选日期，
  下半区（记录列表 / 空提示）向右滑回第 1 页。下面那半边没有东西可圈，才能让给翻页；
- **月记（按月一行）**：月头中间那行年月是**视图开关**——点它，上半区从月历换成这一年的
  十二行：
  - 每行左边是月份（`1 月`…`12 月`），右边一行文字；没写的是灰字『记一句』，写过的那行
    左侧带一个小圆点；
  - 点某一行 = 写 / 改这个月的一句话。**一个月只留一条**，再写就是改；有字的才能删；
    输入框里不写例句——上面那行标题已经说了写什么；
  - 月记模式下左右箭头翻**年**，再点月头（此时只显示年份）切回月历；
  - **月记不进日历**：它不覆盖任何一天，日历上的色带仍然只看记录段——按月记点亮整月
    等于什么都标不出来；
- **记录的改与删都在对话框里**：点记录卡进同一个输入框，有字的才给『删除』。日期那行
  右端一颗『改日期』：点了收起对话框，日历上方冒出一行『拖选新的日期范围』，在格子上
  **重新圈一次**（点单日就是那一天）就回到对话框，刚敲的文字和新的日期都在；横幅上点
  『取消』回到对话框、日期不动。
- **撞上已有的段不关对话框**：服务拒绝时红字说撞到哪一段，文字和日期原样留着，改完
  再存；新建记录走的是同一张框，也一样。
- 日历格子自己不接拖动改期、也没有长按菜单：在格子上拖一下到底是「新建一段」还是「改
  这一段」猜不出来，改范围统一走上面那颗入口。
