# 决定：每日循环每天把模板复制一份到当天，改动不回流

记录：2026-11-04
状态：生效中

## 问题

编排是一段段互相独立的日编排：每天都要重排一遍，而"早上几点做什么"这件事本身天天一样。
需要一种"固定排法"，又不能把编排从"一张纸"变成一套有状态的调度。

## 决定

模板住 `编排.md` 的 `### 循环` 段，与日期段同一个文件、同一套行格式。启动、跨日、打开
编排页时对今天和明天各判断一次：这天还没有段，就把模板整份复制下来，段头标 `·循环`。
复制出来的就是普通条目，改动只影响当天；模板只在两个时刻变——开启循环时取当天那份，
或者点『用今天这份更新循环』。

## 备选与为什么输

**视图叠加**：今天页直接渲染"模板 + 当天自己的条目"，不落副本，天然不会重复、也不会被
模板覆盖。它输在"可编辑"上——允许当天改，就必须回答改的那一条写到哪里；写进当天段，
等于又生成了一份副本，只是把复制这件事藏进了编辑路径，状态更难读；不允许改，那"可编辑"
就不成立。

**条目级"每天重复"标记**：固定的是某一条，而不是整份。它输在归属上——模板散落在各天里，
删一条就得追问"删今天还是删模板"，而用户要的正是整份固定。

**模板单独一个 `编排循环.md`**：文件职责更清楚。它输在整份写入上——两份文件必须在同一个
读改写里一起落盘，否则写一份会抹掉另一份的并发改动；而"一个文件装所有日子"本来就是这张
纸的形态，拆成两份等于把一张纸撕开。

**改当天即改模板**：第二天自动沿用当天的改动，不用再点一次。它输在当天没法随便试——临时
调一下顺序就永久生效，而"今天临时改改"是这张纸最常见的用法。

## 代价

- 明天那份是提前落下的，今晚改了模板它不跟着变，要改就在明天页里改。
- 当天删光条目要到第二天才回到模板；同一天里删掉的不会自己回来（`·循环` 的空段挡着）。
- 模板改了不回溯：昨天以及已经落下的明天，都不受新模板影响。
