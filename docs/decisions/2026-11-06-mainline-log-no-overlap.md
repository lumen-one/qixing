# 决定：主线记录段互不重叠，文字常驻列表，日历只画细条

记录：2026-11-06
状态：生效中

## 问题

记录页原来把"跨了哪几天"和"这几天写了什么"塞进同一个日历格子：每段是一个带描边的
圆角横条，文字写在条里。周行高由可用高度除以周数，日期数字先吃掉 20–32dp，剩下最多
14dp 装 9.5dp 的文字和描边，字被压在数字下面、两条带叠在一起，长文字一律截断。下半区
虽然列了全文，却要**先点某一天**才出现，关键信息不能一眼看见。圈还允许重叠，于是格子
里又多出按行叠放、三条封顶和 `+N` 一整套机制。

## 决定

记录段互不重叠：一段占住的日子不许再落第二段，`addLog` 与 `updateLog` 撞上已有段就
拒绝并报出撞到哪一段，不自动裁剪；只改文字不验。读盘不校验也不迁移。

上半区是不滚动的月历，格子只放日期数字和每段一条色带，色带上不写字；跨周按周分段，
同一周里色带横向不相交。下半区不依赖选中日，进来就常驻列出与本月相交的全部记录段，
每段一张卡：完整正文、起止日期与天数。点某一天只滚到覆盖它的卡并双向高亮，不负责让
文字出现；点卡片才进改文字 / 删除的对话框。色带的画法与"勾选步骤不进记录页"见
[2026-11-07 记录页只记人写的](2026-11-07-mainline-record-decoupled.md)。

## 备选与为什么输

- **把格子里字与数字上下对调**（字在上、数字在下）：挤压一点没变，只是从"挤在下面"
  变成"挤在上面"。更糟的是周行首尾相接，字条到了行顶就离上一行数字只有 2dp、离本行
  数字隔着整行，读者会把它归到上一周；要补得加行距或分隔线，而行高本来就不够。
- **周块流**：把整月拆成 5–6 个周块，每块一行数字紧跟这一周的全宽记录卡，归属最直观。
  但上半区会变成可滚列表，纵向滚动会和日历里的跨周拖选抢手势——日历特意放在不滚动的
  区域里就是为了这件事。要走这条得把跨周拖选改成两次点选，丢掉一个顺手的动作。
- **格子里放短标签 + 下半区全文**：标签要新增字段，34–52dp 的列宽下照样截断，用户得在
  两处之间做映射，不如直接列全文。
- **继续允许重叠、靠 slot 叠放**：不重叠之后 `slot`、`maxBands`、`+N` 和 `bandAt` 的
  slot 维度整套都能删，日历几何从"给重叠留余量"变成"一条轨道排开"。继续留着重叠，
  等于为一个不再需要的能力一直付复杂度。

与 [2026-10-25 月记卡片](2026-10-25-mainline-month-note.md) 的关系：那张卡片里"整月
文字会在每周重复画一遍"这条理由不再成立（细条不写字、下半区按段只列一次），但它剩下
的理由仍成立——整月一段会占满整月，在不重叠口径下还会挡住所有别的段，所以月记仍
单独一段。

## 代价

- 记录段不能再交叉：同一段时间想记两件并行的事，得拆成前后两段或并进一段文字里。
- 光看月历只能知道"哪几天有记录、跨多久"，写了什么要看下半区；整月一屏也变成下半区
  可滚列表，记录多的月份要滚。
- 写入撞段会被拒绝，用户得先改已有段的起止或删掉它，比直接叠一段多一步。
- 手工编辑 `主线.md` 写出的重叠段不归应用管，边界登记在 [架构文档](../architecture.md) §11。
